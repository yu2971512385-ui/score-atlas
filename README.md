# 谱典 · Score Atlas

按乐器、作曲家、演奏家、团体与作品浏览中外音乐资料，查看已核验的公共领域或开放授权曲谱，并在本机将旋律或授权音频转为不同乐器谱。

- 不需要登录，适配 iPhone、Android、平板与电脑
- 中文名、原文名、作品号、乐器与体裁统一搜索
- 42 类乐器与编制、514 位人物/团体、3,555 部作品
- Mutopia 当前 2,124 份 PDF/PDF 套装全量接入
- OpenScore Lieder 1,356 份 CC0 艺术歌曲谱，可下载 MusicXML 与 MuseScore 源文件
- 每份曲谱显示来源、授权状态与核验日期
- 支持开放曲名转谱、授权音频/麦克风主旋律提取、ABC 导入、试听与 PDF 打印
- 未命中内置目录时，可继续联查 Mutopia、IMSLP 与 CPDL

本站已全量收录 Mutopia 开放目录并接入 OpenScore Lieder 公开语料库，但不声称拥有全世界每一种版本。作品本体进入公共领域，不等于任何现代编订、指法、改编或排版版本均可自由下载。
